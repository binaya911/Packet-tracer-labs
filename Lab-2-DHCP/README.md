# Lab 2 - DHCP Configuration

## Overview

Configured a Cisco router as a DHCP server to automatically assign IP addresses to client devices.

## Network Components

- 1 Router
- 1 Switch
- 2 PCs

## DHCP Configuration

- DHCP Pool: OFFICE
- Network: 192.168.1.0/24
- Default Gateway: 192.168.1.1
- DNS Server: 8.8.8.8

## Skills Practiced

- DHCP Configuration
- Router CLI
- IP Addressing
- Network Troubleshooting
- Connectivity Testing

## Verification

Verified that client devices automatically received IP addresses and successfully communicated using ICMP ping.
